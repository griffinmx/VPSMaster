# VPSMaster 五阶段开发路线

路线以[中文README](../../README.md)为准。Phase 1为当前Beta基础；Phase 2–5均为后续规划，尚未实现的能力不属于Beta.1，不承诺固定发布时间。

## Phase 1 — VPS 综合检测

当前：系统与可见资源、接口/连通性/DNS/TCP/TLS、UDP及条件允许的ICMP/TCP、IP/ASN/BGP、公开网页可达性、只读安全体检与本地JSON/Markdown/恢复日志。实际覆盖取决于工具、权限及第三方来源，网页可达不等于解锁或播放。

## Phase 2 — 检测能力完善与备份回滚（Planned）

完善CLI彩色综合报表、CPU/磁盘性能基准、三网测速、IP情报交叉验证、线路建议与安全基线。建立配置快照、差异对比、基础恢复和可验证的恢复流程，为部署与加固提供保障。负载测试仍需单独明确授权和资源预算。

## Phase 3 — 一键代理部署（Planned）

常见代理协议的一键安装、服务配置、状态检测、更新与卸载。初期优先无需域名的基础方式，再逐步支持域名、证书及订阅管理。强调配置和凭据安全、服务生命周期及故障诊断，不用公网明文传输暴露订阅凭据。

## Phase 4 — 一键安全加固（Planned，未来重点）

SSH登录保护与密钥策略、UFW/nftables、Fail2ban、系统更新、权限和端口管理。提供方案选择、风险解释、修改预览、执行验证和有条件回滚。

涉及SSH、防火墙或其他可能影响连接的变更，必须经用户明确确认。遵循：

**检测 → 解释 → 预览 → 确认 → 备份 → 执行 → 验证 → 回滚**

保护SSH管理连接和既有业务端口；不默认执行高风险无人确认变更，不通过关闭安全保护“修复”。回滚需可靠前提，不承诺恢复全部断网、云安全组、重启或宿主故障。

## Phase 5 — Web UI 与服务器管理（Planned，长期规划）

本地Web面板、检测报告展示、安全风险、部署服务、备份恢复、多VPS与可选服务管理。默认不向公网开放管理入口，认证、权限与凭据保护是基础要求。
