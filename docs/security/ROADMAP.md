# Linux VPS 安全诊断与加固路线 / Roadmap

项目从可信检测逐步发展为 Linux 服务器安全诊断与加固助手。Phase 1 是当前基础，Phase 2–5 均为 Planned，不属于当前 Beta，不承诺固定交付时间。

## Phase 1 — VPS 综合检测（当前 Beta）

系统与可见资源、DNS/IPv4/IPv6/TCP/TLS、原生 UDP 与可选系统 ICMP/TCP 路由、BGP/ASN/IP 信息、基础只读安全体检、本地报告与恢复。系统依赖、权限和第三方数据决定实际覆盖；媒体仅公开网页可达性。[当前限制](../release/KNOWN_LIMITATIONS.md)

## Phase 2 — 检测能力完善（Planned）

- CPU、磁盘性能基准，独立明确授权和负载预算。
- 中国大陆电信、联通、移动测速覆盖和可靠性完善。
- 扩展 IP 情报交叉验证、网络线路分析与诊断建议。
- 更完整的 Linux 安全基线、VPS 购买验收和性能分析。

## Phase 3 — 一键安全加固（Planned，未来重点）

- SSH 配置、登录保护、密钥认证策略。
- UFW/nftables 配置及 Fail2ban 暴力破解防护。
- 系统更新/补丁检查，用户权限与文件权限加固。
- 不必要服务与开放端口管理，Linux 安全基线。
- 可选择的加固方案、风险解释与修改预览。

不会默认自动修改服务器配置。执行必须经过用户明确确认；检测到风险不等于获得修改授权。不通过关闭安全保护或放宽权限“修复”。

## Phase 4 — 安全备份、回滚与持续监控（Planned）

- 修改前备份 SSH、防火墙及相关配置，展示变更差异。
- 验证并保留 SSH 管理通道，考虑业务端口和云安全组，执行后重新验证连接。
- 在具备可靠机制时提供超时回滚、操作审计及恢复向导。
- 定期安全体检、配置漂移、异常登录提醒、网络稳定性与历史报告对比。

重点避免用户加固 SSH/防火墙时失去管理访问；不能承诺自动恢复全部断网、重启、云安全组或宿主故障。涉及高风险变更不得无人确认执行，必须说明回滚前提与人工恢复入口。

## Phase 5 — Web UI 与可视化管理（长期规划）

本地 Web 面板、服务器状态、安全风险和加固任务、备份/恢复界面、多 VPS 及可选服务部署维护。认证、权限、敏感凭据及访问安全是前提，默认不向公网开放管理入口。

## 长期安全原则

**检测 → 解释 → 预览 → 确认 → 备份 → 执行 → 验证 → 回滚**

默认只读、显式授权、幂等与审计、管理连接及业务端口保护。未知不能视为安全；有依据地描述风险，不提供无法解释的绝对安全评分。
