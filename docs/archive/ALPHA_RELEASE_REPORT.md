# v0.1.0-alpha 发布前报告

日期：2026-11-01。版本元数据0.1.0a0，候选ZIP名v0.1.0-alpha。结论：**可内部Alpha试用；不建议现在公开发布，尚缺全新Ubuntu镜像安装验证及发布摘要可信分发确认。** 本轮未公开发布或合并主分支。

## 修复

1. 新增标准库离线安装器，venv --without-pip，无sudo/pip/包下载；不覆盖已有目录，失败和取消清理自建目录。包括安装路径含空格验收。
2. 增加逐文件SHA256清单、ZIP摘要、路径/符号链接/篡改拒绝，并统一LF，避免Git换行导致校验失效。摘要须来自可信渠道，不能替代发布签名。
3. HTTP/API/定位/媒体/吞吐CLI请求采用可终止子进程，覆盖阻塞DNS；网络通常20s、吞吐25s，本机命令8s，DNS探测2–5s。SIGINT/SIGTERM取消活动worker，保留已完成结果。
4. 增加统一result_schema_version=1/result_items，五状态及来源、时间、方法、指标、错误、置信范围、限制；保留旧报告字段以避免无关迁移。
5. suite及独立quality/ipquality/media/bandwidth命令增量保存；IP逐来源、测速逐样本回调。报告独占创建，日志单条4MiB、总64MiB；失败提示并返回非零，可恢复最后完整事件。
6. UDP路由最多3轮、共享90s软预算，显示每跳实际发送、响应、超时与响应缺失统计；明确不等于转发丢包率。真实回环三次回应+一次无回应得到4发3收1超时/25%响应缺失。

## 未闭合门槛与剩余风险

- **全新操作系统镜像安装尚未验证**：本轮是已有Ubuntu上的空HOME及全新环境，不证明系统没有先前安装过Python/venv组件。安装器检测失败会退出，不自动更改系统。09-01全量验收不能因此勾完成。
- 公开发布须从可信来源独立提供ZIP摘要；本轮无签名密钥、无远程发布、无远程CI结果。所有构建/测试包仍在本地工作区。
- CLI默认网络worker有上限；路由90s为软预算，正在进行的定位请求可能额外耗时最多一个worker上限。不是CPU/内存/所有系统调用的硬隔离沙箱。
- 第三方真实网络/地区/数据库字段受出口和目标限制。Alpha本轮主要实测本机回环错误与取消，不宣称海外网络、付费数据库、账号播放或专业吞吐容量已验收。
- SIGKILL、断电、磁盘/文件系统损坏以及未完成的探测无法保证结果保存；先前完整日志记录为恢复依据。路径应在可信用户目录，未承诺抵御共享目录所有竞态攻击。
- 配置哈希仅覆盖指定可读路径，不是完整系统写入审计。仅系统/数据读取和本地输出写入，不修改SSH/防火墙/路由/DNS，无完整报告上传。
- ARM、容器全场景、全新Server/Desktop、真实VPS、所有信号时序、可选带宽worker真实容量未验证。兼容和支持范围必须按README披露。

## P2与发布建议

P0/P1已完成主要代码修复和现有VM实测，但干净系统镜像门槛未闭合，故不扩展P2代码。04-09/05-03/08-05保留已有证据与保守边界；09-04仍缺全新安装形态验收。

建议把当前包作为内部Alpha候选供审阅；补全新镜像验证、确认摘要分发后再决定公开Alpha。保持大功能关闭/未实现声明。用户批准发布是后续动作，本轮不代为执行。
