# VPSMaster 第三方接口与数据条款

源码MIT许可与第三方服务/数据许可不同。本包不分发地理数据库、API密钥或第三方测速二进制，不提供共享查询代理，也不代表服务商授权无限访问或再分发。

核对入口与适用约束（以服务商当前条款和用户套餐为准）：

| 来源 | 官方入口 | 本版使用与限制 |
| --- | --- | --- |
| ipapi.is | https://ipapi.is/developers.html | 可匿名查询，但字段/日限额受限；不把缺失风险标记当安全。密钥只由用户本地提供，不随包分发 |
| proxycheck.io | https://proxycheck.io/terms/ | 查询即受条款约束；不得规避免费限额或损害服务，失败/限额不换账号绕过 |
| IP2Location.io | https://www.ip2location.io/terms-of-service | 集成不等于取得数据再分发权；不批量重建数据库、不公开密钥、不把原始API作为独立服务再售；适用缓存条款含30天限制 |
| IPWhois / ipwho.is | https://ipwhois.io/terms | 有限个人/内部使用权，不代表允许镜像、转售或任意再分发；只作可选有限跳点查询 |
| RIPEstat / RIS | https://stat.ripe.net/docs/data-api/ripestat-data-api | 保留来源，有限查询；AS路径是采集器观察，服务政策独立适用 |
| AbuseIPDB | https://docs.abuseipdb.com/ | 用户可选密钥只读查询；不提交举报，不分发服务访问凭据 |

**保留与分享：** 本工具不会自动删除用户历史报告。用户须遵守实际数据来源/套餐的保留与分享限制；尤其含IP2Location数据的存档需要按适用条款清理、刷新或取得另行许可。不要公开原始API响应或将其作为可再许可数据库分发。报告脱敏不等于获得再分发许可。

公网测速端点和流媒体页面仍受各自条款、限额、访问控制约束。目录公开不等于授权持续高负载；大陆候选保持实验性、默认关闭，未知许可/可用性不提升为可靠默认服务。测试不禁用TLS验证，不绕过登录或付费播放权限。

该清单是实现/文档边界核对，不是独立法律意见或所有套餐/地区用途的完整合规认证。服务政策变化、长期商业托管、公开数据再分发须另行审查。
