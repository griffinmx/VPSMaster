# IPQuality 风格功能覆盖与外部资源

2026-11-01。目标是借鉴清楚的分区展示，优先自主实现，不直接运行或拼接第三方脚本。

| 分区 | 当前代码 | 限制/后续 |
|---|---|---|
| 顶部概览 | IP、ASN、运营商、估计位置、网络类型、风险标签、来源冲突数、覆盖率、时间 | 默认隐藏IP；没有取得风险标签不等于安全；不是综合纯净度评分 |
| 多数据库依据 | ipapi.is、proxycheck.io、IP2Location、可选AbuseIPDB；来源类型/代理/VPN/Tor对照 | 缺字段/密钥保留未知；并未覆盖上游所有数据库 |
| 流媒体/在线服务 | suite下独立模块，保留限制、片库、未知等证据 | 账号、DRM和实际播放未验证；IPQuality本身不作为我们的数据API |
| 邮件网络 | `ipquality --mail-probes` / `suite --mail-probes`；PTR、正向一致性、单目标出站TCP/25 | 默认跳过额外探测；不发邮件；不证明入站25、全部邮件服务或投递信誉 |
| DNSBL | 明确显示未查询 | 每个来源的使用条款、resolver限制、查询控制地址、NXDOMAIN/限流/错误码需要先实现，不能把空响应当干净 |
| IPMap/定位地图 | 尚未接入 | 待选择具体来源并核对公开API/许可/费用/查询隐私；不会自动抓取需要登录或限制访问的网页 |

## 实际源码研究及许可

阅读 [xykt/IPQuality LICENSE](https://github.com/xykt/IPQuality/blob/main/LICENSE) 和 [ip.sh](https://github.com/xykt/IPQuality/blob/main/ip.sh)：包括邮件端口与 `check_dnsbl_parallel` / `check_dnsbl` 入口及结构化邮件结果组织。根许可证为GNU AGPL v3文本。我们没有复制其实现代码、数据库清单或服务网页抓取逻辑；报告布局和检测需求作为设计参考，检测代码自主编写。

该入口的DNSBL分类依赖查询返回内容。我们不会照搬“空结果即干净”之类假设，必须区分查询失败、服务拒绝、未列出及命中，再考虑显示统计。也不会认为调用外部程序就自动免除许可责任。若以后确需引入AGPL实现或分发其组件，先单独评估并征求用户确认。

外部资源可通过受控API适配器、本地合法数据库或明确可选的查询链接接入。每条来源需记录查询时间、来源版本/地址、字段、错误、限制及费用。网页查询链接若携带公网IP，应在用户明确选择时才打开。未具备的资源统一列待接入，不能伪造地图、数据库结果或风险分数。
