# ProxyDoctor 1.0.0b1 / v1.0.0-beta.1

Public Beta candidate, not the final release. Publication requires the separate
acceptance report matching the exact ZIP SHA256; source changes alone are not a pass.

- Preserve explicit no-bytecode flags on provided launchers and Python workers.
- Preserve route permission/dependency/network errors in CLI and JSON.
- Add bounded route ASN/operator metadata with provider, time and estimated-geography labels.
- Adapt overview/frame widths to narrow interactive terminals; filter control and bidi characters.
- Preserve cancellation reports and close journals when interrupted during context entry.
- Retain system/resource, UDP route, IP/provider evidence, public media page,
  read-only security, opt-in bounded bandwidth and report/recovery capabilities.

ICMP/TCP require system traceroute; permissions vary. No automatic elevation.
China candidates are experimental and default off. Small probes are not capacity
measurements. Media is page reachability only, BGP is RIPE RIS collector evidence.
No CPU/disk benchmark, monitor, proxy deployment or Web UI added.

See KNOWN_LIMITATIONS.md, README.md, README.en.md and THIRD_PARTY_NOTICES.md.
